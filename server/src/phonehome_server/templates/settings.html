Settings

Phone behavior

Greetings, prompts, the ringer and recording limits, as JSON. An empty object {} means the phone's built-in defaults: a chime, then a beep, then up to 3 minutes of recording. A proper editor for greetings and prompts comes later (phase 5). The phone picks up changes within a minute. Current version: {{ version }}.

Example 
{
  "recording": {"max_duration_s": 120, "warning_before_end_s": 20},
  "greetings": [
    {"id": "default", "asset": "builtin:chime", "title": "Chime"},
    {"id": "xmas", "asset": "xmas-2026", "title": "Christmas", "priority": 10,
     "rules": {"dates": [{"start": "12-01", "end": "12-31"}]}}
  ],
  "assets": {"xmas-2026": {"filename": "xmas-2026.flac"}}
}

Asset files go in the archive's greetings/, prompts/ or ring-sounds/ folder. Their checksums are filled in when you save.
